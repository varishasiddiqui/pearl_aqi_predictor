# 🌍 Pearls AQI Predictor

## Project Overview
Predict the Air Quality Index (AQI) in Karachi for the next 3 days using a 100% serverless MLOps stack.

## Tech Stack
- **Data**: OpenWeather API, Open-Meteo API
- **Feature Store**: Hopsworks
- **Models**: Random Forest, Ridge Regression, LSTM (TensorFlow)
- **Best Model**: Ridge Regression (RMSE: 5.29)
- **Dashboard**: Streamlit
- **CI/CD**: GitHub Actions
- **Explainability**: SHAP

## Features
- Real-time AQI monitoring
- 3-day AQI forecast
- SHAP-based feature importance
- Hazardous AQI alerts
- Automated data pipeline (hourly)
- Automated training pipeline (daily)
